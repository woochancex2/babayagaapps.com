아이폰용 패스루프 · iOS 17 이상

질문, 버그, 아이디어는 babayaga@babayagaapps.com로 보내 주세요. 아이폰 기종, iOS 버전, 패스루프 버전(설정 → 버전)을 함께 적어 주시면 좋아요. 보통 며칠 안에 답장드려요.

Anki 덱 가져오기

  1. 컴퓨터의 Anki에서 덱을 Anki 덱 패키지(.apkg)로 내보내요. 진도도 함께 가져오려면 복습 일정 정보를 포함해 주세요.
  2. 파일을 아이폰으로 옮겨요. 파일 앱이나 iCloud Drive에 저장하거나 AirDrop으로 보내면 돼요.
  3. 패스루프에서 내 문제 → ···(문제집 도구) → 안키 파일 가져오기를 누르고 파일과 가져올 문제집을 골라요.

메일·메신저·사파리에서 받은 .apkg 파일은 파일을 누르고 공유 → 패스루프를 고르면 바로 가져오기가 열려요.

화면을 닫아도 가져오기는 계속되고, iOS가 멈추면 다음에 앱을 열 때 이어서 해요. 고른 문제집 기준 한 번에 3만 장 이상(아이폰 메모리에 따라 최대 15만 장) 가져올 수 있고, 전체 컬렉션 파일(.colpkg)도 돼요. 카드 일부를 보여 줄 수 없으면 가져오기 화면에서 이유와 카드 수를 알려 드려요.

쓰던 AI로 카드 만들기

내 문제 탭에서 AI로 문제 만들기를 시작하고, 주제와 문항 수·유형, 쓸 AI를 고르세요. 패스루프가 요청문을 복사하고 그 AI를 열어 줘요. 붙여 넣고(원하면 내 자료도 함께) 답을 복사해 돌아와 붙여 넣으면 문제집이 돼요. 패스루프는 AI를 직접 부르지 않아요. 직접 입력하거나 CSV 파일로 가져와도 돼요.

Anki가 없다면: AI에게 .apkg 파일 부탁하기

50장보다 많이 필요하면 안키 파일 가져오기 → AI에게 .apkg 만들어 달라고 하기에서 학습 내용과 카드 수를 고르세요. 패스루프가 코드를 실행할 수 있는 AI 앱에 보낼 요청문을 복사해 줘요. 가진 사진·PDF·음성·영상을 함께 올려도 돼요. AI가 준 .apkg 파일을 누르고 공유 → 패스루프를 고르면 돼요. 앞면·뒷면 카드로 만들어져요.

내보내기·백업·새 아이폰으로 옮기기

  • 문제집 내보내기: 문제집에서 내보내기를 고르고 안키 덱 (.apkg)과 학습 진도 포함을 고르면 Anki에서 열 수 있어요. CSV (표)로도 저장돼요.
  • 백업: 설정 → 학습 데이터 → 백업 및 복원 → 백업 파일 만들기. 카드 진도·문제집·문제집 설정·메모·룹룹 하우스가 한 파일에 담겨요.
  • 자동 백업: 하루에 한 번 학습 데이터를 아이폰에 보관하고 최근 7개를 남겨요. 이미지·음성은 빠지니 전체 사본은 백업 파일로 만들어 주세요.

새 아이폰으로 옮기기

  1. 예전 아이폰에서 이미지·음성을 포함해 백업 파일을 만들어요.
  2. 파일 앱이나 iCloud Drive에 저장하거나 새 아이폰으로 AirDrop해요.
  3. 새 아이폰의 패스루프에서 설정 → 학습 데이터 → 백업 및 복원 → 백업 파일에서 복원을 눌러요. 복원은 다음에 앱을 열 때 적용돼요.

패스루프 Ultra

  • Ultra는 한 번 구매로 Listen 모드, 룹룹 하우스 Ultra 컬렉션, 앱 아이콘 9색을 열어요. 무료인 기능은 계속 무료예요.
  • 7일 무료 체험: 자동 결제가 없어요. 끝나면 Ultra 기능만 잠기고 문제집·학습 기록·코인은 그대로 남아요.
  • 가족 공유가 켜져 있어 가족 구성원도 Ultra를 쓸 수 있어요.
  • 구매 복원: 설정 → PASS LOOP 응원하기 → 구매 복원.
  • 환불은 Apple(reportaproblem.apple.com)에서 요청해요. 환불되면 Ultra 기능은 꺼지지만 문제집·기록·코인은 지워지지 않아요.
  • PASS LOOP 응원하기의 팁은 고마움을 전하는 선택 사항이고, 어떤 기능도 열지 않아요.

Listen 모드

학습 화면의 헤드폰 버튼으로 시작해요. 이어폰을 한 번 누르면 일시정지, 두 번은 보통, 세 번은 다시예요. 어려움·쉬움, 다시 듣기, 되돌리기는 Listen 화면에 있어요. 카드는 아이폰 음성으로 읽어 주거나, 아이폰 안에서 만드는 자연스러운 AI 음성(처음 한 번 약 400MB 내려받기, 서버로 아무것도 보내지 않아요)으로 읽어 줘요. AI 음성은 메모리 4GB 이상인 아이폰에서 쓸 수 있고 중국어는 읽지 않아요. 그 밖의 아이폰과 중국어 카드는 아이폰 음성으로 읽어요. 더 자연스러운 아이폰 음성은 설정 앱 → 손쉬운 사용 → 읽기 및 말하기 → 음성에서 무료로 내려받을 수 있어요.

알아 두면 좋아요

  • iOS 17 이상 아이폰 전용이에요. iPad·Android·웹 버전은 없어요.
  • 한국어, 영어, 일본어, 중국어(번체)를 지원하고, 아이폰 언어 설정을 따라가요.
  • 홈 화면·잠금 화면 위젯으로 오늘 공부할 카드, 연속 학습, 룹룹 날씨를 볼 수 있어요. 홈 화면을 길게 눌러 패스루프 위젯을 추가하세요.
  • 동기화와 계정이 없어요. 문제집은 .apkg 파일로, 진도와 룹룹 하우스는 백업 파일로 옮겨요.
  • Anki 애드온은 패스루프에서 실행되지 않아요.
  • 모든 데이터는 내 아이폰에 있어요. 개인정보처리방침을 참고하세요.

문제 알리기

무슨 일이 있었는지, 어떤 순서로 하면 생기는지, iOS와 패스루프 버전을 알려 주세요. 스크린샷이 있으면 큰 도움이 돼요. 특정 문제집에서만 문제가 생기면 그 문제집을 설명해 주시고, 내용을 보여 줘도 괜찮을 때만 파일을 첨부해 주세요.
