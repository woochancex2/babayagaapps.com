プライバシーポリシー

施行日 2026年11月14日 · bitglass

bitglass（以下「当方」）は、iPhone・AndroidアプリのPASS LOOPとウェブサイトbabayagaapps.comを運営しています。このポリシーでは、それぞれが扱う情報について説明します。韓国「個人情報保護法」第30条に基づいて公開するものでもあります。このページは英語版の翻訳です。内容に違いがある場合は英語版が優先されます。

  • PASS LOOPにはアカウント、当方のサーバー、広告、分析・トラッキングがありません。オプションのAI音声は、Hugging FaceまたはGitHubから一度ダウンロードしたあと、スマホの中で動きます。
  • デッキ、カード、学習記録はあなたのスマホの中だけに保存され、当方に送られることはありません。
  • 天気、都市検索、購入など、プラットフォームのサービスを使う機能はそのサービスが処理します。iPhoneではApple、AndroidではGoogleとMET Norwayです。アプリが端末の位置情報（GPS）を読み取ることはありません。
  • ウェブサイトはCloudflare Web Analyticsで訪問数を数えます。Cookieを使わず、訪問者を特定しません。それ以外はホスティング事業者のサーバーログがあるだけです。

アプリ — AI音声のダウンロード（任意・Ultra）

ListenモードでAI音声のダウンロードを選ぶと、アプリはSupertone Inc.が作ったSupertonic 3音声モデル（約400MB）をHugging Face（huggingface.co）からダウンロードします。Hugging Faceを使えないときは、当方がGitHub（github.com）に置いた無改変のコピーからダウンロードします。一般的なダウンロードと同じく、このリクエストにはIPアドレスと基本的な端末・アプリの情報が含まれ、各事業者のプライバシーポリシー（Hugging Face、GitHub）に従って扱われます。学習内容やアカウント情報は送りません。ダウンロード後はスマホの中で音声を作り、読み上げる文字が端末の外に出ることはありません。ダウンロードボタンを押さない限り、何もダウンロードしません。Androidでは、リクエストヘッダーにアプリ名とバージョン（例：「PassLoop-Android/1.3.1」）も含まれます。

アプリ — マイク・カメラ・動き（任意）

これらの許可は、その機能を初めて使うときだけ確認します。許可しなくても、アプリのほかの機能は使えます。以下はすべてスマホの中だけで使い、運営者にもほかの場所にも送りません。

  • マイク：学習画面で自分の発音を録音してカードの音声と聞き比べるとき、またはカードに録音を付けるときに使います。学習画面での録音は一時ファイルで、別のカードへ進む・画面を閉じる・Listenを始めると消えます。カードに付けた録音は、そのカードの添付ファイルとしてスマホの中に保存されます。録音の分析や音声認識には使いません。1回の録音は最長2分です。
  • カメラ（iPhone）：カードに付ける写真を撮るときだけ使います。写真はカードの添付ファイルとしてスマホの中に保存されます。Androidではカメラアプリが撮影し、PASS LOOPはカメラの許可を求めません。
  • モーション（iPhone・任意）：設定 › Listen › 実験機能で「頭の動きで評価」をオンにしたときだけ、頭の動きに対応したAirPodsから頭の向きの値を読み取り、うなずきと首振りを判定します。値はその場で使うだけで、保存せず、端末の外にも出ません。オフの間は読み取りません。Androidにはこの機能はありません。
  • 音声認識：アプリは音声認識をしません。iPhoneでSiriやショートカットから「Listen開始」と言うと、言葉の聞き取りはAppleが行い（Appleのプライバシーポリシーに従います）、PASS LOOPが受け取るのはListenを始める実行要求だけで、声や言葉は受け取りません。AndroidにはSiriの連携はなく、アプリアイコンの長押しでListenを始めます。
  • ロック画面：Listen中、ロック画面（iPhoneはライブアクティビティとDynamic Island、Androidは通知）にデッキ名・残りのカード数・「もう一度」「一時停止」「ふつう」のボタンが表示されます。カードの文字は表示されません。プッシュサーバーなしで、アプリの中だけで更新されます。
  • カードに付けた写真・録音はカードと同じ扱いです。書き出しファイルやバックアップ、スマホのバックアップ（iPhoneはiCloud、AndroidはGoogle）に含まれることがあります。

アプリ — あなた自身が送る場合

  • 外部のAIでカードを作る：アプリがAIを呼び出すことはありません。リクエストをクリップボードにコピーし、あなたが選んだAIのアプリやサイトを開くだけです。そこに貼り付けた内容は、そのサービスのポリシーに従って扱われます。
  • 共有・エクスポート・バックアップファイル：.apkg、CSV、バックアップファイル（.passloopbackup）は、あなたが選んだ場所（「ファイル」App、iCloud Drive、AirDropなど）に保存されます。バックアップファイルは暗号化されていないため、安全な場所に保管してください。
  • リンク：カード内のリンクをタップすると、ブラウザで開きます。
  • アプリから当方に連絡する（iPhone・Android）：設定 › アプリ情報 › 「質問・不具合・アイデアを送る」を選ぶと、お使いのメールアプリが開き、件名、短い案内、アプリのバージョン・OSのバージョン・機種・言語を書いた1行があらかじめ入力されます。編集や削除もできます。PASS LOOP自体は何も送信せず、メールはあなたのメールアカウントから当方に届き、当方に書いてくださった他のメールと同じように扱います。

2. 保存期間と削除

  • アプリのデータは、あなたが削除するかアプリを削除するまでスマホに残ります。アプリを削除すると、アプリの保存領域も消えます。削除したデッキは、ゴミ箱から戻すことも、ゴミ箱から消すこともできます。
  • 発音の録音・添付：学習画面での発音の録音は一時ファイルで、次へ進むか画面を閉じると消えます。カードに付けた写真・録音は、カードを削除するか添付を外すまでスマホに残ります。
  • 自動バックアップ：1日に1回まで学習データを端末内にバックアップし、最新の7件を残します（画像・音声は除く）。バックアップから復元するときは、それまでのデータを安全のため端末内に残します（最新の3件）。いずれもアプリの保存領域にあり、アプリと一緒に削除されます。
  • Androidの端末バックアップ：Androidの設定によっては、アプリのデータ（デッキ、学習履歴、設定）がGoogleアカウントへのスマホのバックアップに含まれることがあります。このバックアップはGoogleが独自の規約に従って管理します。AI音声モデルとウィジェット用のコピーは含まれません。
  • アプリの外にあるコピー（スマホのバックアップ［iPhoneはiCloud、AndroidはGoogle］、エクスポートしたファイル、AIに貼り付けた文章）は、あなたが管理するものです。
  • メールは返信後1年間保管し、その後すみやかに削除します。
  • 感謝リストのニックネームは、削除のご依頼があるまで公開リストに残し、ご依頼があればすみやかに削除します。
  • ウェブサイトのログと訪問統計は、各事業者の保存方針に従います。

6. 情報の保護

  • アプリのデータは、iOSのアプリサンドボックスと端末の暗号化で守られ、当方のサーバーに送られることはありません。
  • Androidでも、アプリのデータはアプリのサンドボックスとスマホの暗号化で保護され、当方のサーバーには送られません。
  • カードを表示する画面は、外部へのネットワーク接続をブロックしています。
  • バックアップファイルは、復元の前にファイルごとにハッシュで確認します。
  • サポートのメールは、当方だけがアクセスできるアカウントで管理します。

7. Cookieとトラッカー

アプリにはCookie、広告識別子、トラッキングツールはありません。ウェブサイトもCookieを使わず、効果音と昼/夜の設定、オープニングを見たかどうかの記録、ゲームの記録は、ブラウザの保存領域にだけ残ります。訪問数を数えるCloudflare Web Analyticsは、端末に何も保存しません。

8. お子さま

PASS LOOPにはアカウントがなく、当方は個人情報を受け取らないため、年齢を確認しません。14歳未満のお子さまが外部のAIサービスやリンクを使うときは、保護者の方が一緒に確認してください。
