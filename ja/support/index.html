iPhone用PASS LOOP · iOS 17以降

ご質問、不具合、アイデアは babayaga@babayagaapps.com までお送りください。iPhoneの機種、iOSのバージョン、PASS LOOPのバージョン（設定 → バージョン）を書いていただけると助かります。通常は数日以内にお返事します。

Ankiのデッキを持ってくる

  1. パソコンのAnkiで、デッキをAnkiデッキパッケージ（.apkg）として書き出します。スケジュール情報を含めると、学習の進み具合も一緒に移せます。
  2. ファイルをiPhoneに移します。「ファイル」AppやiCloud Driveに保存するか、AirDropで送ってください。
  3. PASS LOOPで デッキ → ···（デッキツール） → Ankiファイルを取り込む を開き、ファイルを選んでから、取り込みたいデッキを選びます。

メール、メッセージ、Safariで.apkgファイルを受け取ったら、タップして 共有 → PASS LOOP を選ぶと、すぐに取り込み画面が開きます。

取り込みは画面を閉じても続きます。iOSに止められた場合は、次にアプリを開いたときに再開します。選んだデッキから一度に30,000枚以上（iPhoneのメモリによって最大150,000枚）のカードを取り込めて、コレクション全体のファイル（.colpkg）にも対応しています。カードの一部を表示できない場合は、その理由と枚数を取り込み画面に示します。

いつものAIでカードを作る

デッキ タブで AIでカードを作成 を始め、テーマ、カードの枚数と種類、使うAIを選びます。PASS LOOPが用意したリクエストをコピーして、そのAIを開きます。そこに貼り付け（自分のメモを足してもかまいません）、回答をコピーして戻り、貼り付けるとデッキになります。PASS LOOPがAIを直接呼び出すことはありません。カードを手で入力したり、CSVファイルを取り込んだりもできます。

Ankiがなくても大丈夫。AIに.apkgファイルを作ってもらう

50枚より多く作りたいときは、Ankiファイルを取り込む → AIに .apkg を作ってもらう を開き、テーマとカードの枚数を入れます。PASS LOOPが、コードを実行できるAIアプリ向けのリクエストをコピーします。手持ちの写真、PDF、音声、動画を添付してもかまいません。AIが作った.apkgファイルを開き、共有 → PASS LOOP を選んでください。作られるのは表と裏のカードです。

エクスポート、バックアップ、新しいiPhoneへの移行

  • デッキのエクスポート：デッキで エクスポート を選び、Ankiで開くなら Ankiデッキ（.apkg） と 学習の進捗を含める を、表として使うなら CSV（表） を選びます。
  • バックアップ：設定 → 学習データ → バックアップと復元 → バックアップファイルを作成。ファイルには、カードの進み具合、デッキ、デッキオプション、メモ、ループレットハウスが入ります。
  • 自動バックアップ：1日に1回、学習データをiPhoneの中に保存し、最新の7件を残します。画像と音声は含まれないため、すべてを残したいときはバックアップファイルを作ってください。

新しいiPhoneに移る

  1. 古いiPhoneで、画像と音声を含めてバックアップファイルを作ります。
  2. 「ファイル」AppやiCloud Driveに保存するか、AirDropで新しいiPhoneに送ります。
  3. 新しいiPhoneでPASS LOOPを開き、設定 → 学習データ → バックアップと復元 → バックアップファイルから復元 を選びます。復元は次にアプリを開いたときに反映されます。

PASS LOOP Ultra

  • Ultraは買い切りで、Listenモード、ループレットハウスのUltraコレクション、アプリアイコン9色が使えます。無料の機能は、これからも無料のままです。
  • 7日間無料体験：自動で課金されることはありません。終わるとUltraの機能だけが止まり、デッキ、学習記録、コインは消えずに残ります。
  • ファミリー共有に対応しているので、ファミリーグループのみんなもUltraを使えます。
  • 購入の復元：設定 → PASS LOOPを応援 → 購入を復元。
  • 返金はAppleの reportaproblem.apple.com から申請します。返金されるとUltraの機能はオフになりますが、デッキ、学習記録、コインが消えることはありません。
  • PASS LOOPを応援 のチップは任意のお礼で、機能が解放されるものではありません。

Listenモード

学習画面のヘッドホンボタンから始めます。イヤホンでは、1回押すと一時停止、2回で「ふつう」、3回で「もう一度」です。「難しい」と「簡単」、「もう一度聞く」と「元に戻す」はListenの画面にあります。カードはiPhoneの声か、iPhoneの中で動くオプションの自然なAI音声で読み上げます（約400MBを一度だけダウンロード。サーバーには何も送りません）。AI音声はメモリが4GB以上のiPhoneで使え、中国語は読み上げません。それ以外のiPhoneと中国語のカードは、iPhoneの声で読み上げます。より自然なiPhoneの声は、iOSの 設定 → アクセシビリティ → 読み上げコンテンツ → 声 から無料でダウンロードできます。

知っておくと便利なこと

  • iPhone専用、iOS 17以降です。iPad版、Android版、Web版はありません。
  • アプリは英語、韓国語、日本語、繁体字中国語に対応し、iPhoneの言語設定に従います。
  • ホーム画面とロック画面のウィジェットに、今日のカード、連続学習、ループレットの天気が表示されます。ホーム画面を長押しして、PASS LOOPを追加してください。
  • 同期とアカウントはありません。デッキは.apkgファイルで、学習の進み具合とループレットハウスはバックアップファイルで移します。
  • AnkiのアドオンはPASS LOOPでは動きません。
  • データはすべてiPhoneに保存されます。プライバシーポリシーをご覧ください。

問題を報告する

何が起きたか、そこに至る手順、iOSとPASS LOOPのバージョンを教えてください。スクリーンショットがあるととても助かります。特定のデッキで問題が起きる場合は、その内容を説明してください。デッキファイルは、中身を見られても構わない場合にだけ添付してください。
