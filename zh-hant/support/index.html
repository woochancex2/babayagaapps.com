支援

iPhone 版 PASS LOOP · iOS 17 以上

有問題、錯誤或想法，請寫信到 babayaga@babayagaapps.com。請附上你的 iPhone 型號、iOS 版本和 PASS LOOP 版本（設定 → 版本）。我們通常會在幾天內回覆。

帶來你的 Anki 牌組

  1. 在電腦版 Anki 中，把牌組匯出為 Anki 牌組套件（.apkg）。一併匯出排程資訊，學習進度就能跟著帶過來。
  2. 把檔案放到 iPhone 上：存到「檔案」App 或 iCloud 雲碟，或用 AirDrop 傳送。
  3. 在 PASS LOOP 中前往 牌組 → ···（牌組工具）→ 匯入 Anki 檔案，選擇檔案，再挑選想要的牌組。

在郵件、訊息或 Safari 收到 .apkg 檔？點一下檔案，選擇 分享 → PASS LOOP，就會立刻打開匯入畫面。

即使關閉畫面，匯入也會繼續；如果被 iOS 中斷，下次打開 App 時會接著進行。一次可以從選擇的牌組匯入至少 30,000 張卡片（視 iPhone 的記憶體，最多 150,000 張），也支援 Anki 的收藏檔（.colpkg）。如果卡片有部分內容無法顯示，匯入畫面會列出原因和卡片數量。

用你慣用的 AI 製作卡片

在 牌組 分頁開始 用 AI 建立卡片，選擇主題、卡片數量和種類，再選擇你的 AI。PASS LOOP 會複製一段準備好的請求，並打開那個 AI。把它貼上（也可以加上自己的說明），複製 AI 的回答，回到 App 貼上，就會變成一個牌組。PASS LOOP 從不自己呼叫 AI。你也可以自己輸入卡片，或匯入 CSV 檔。

沒有 Anki？請 AI 幫你做 .apkg 檔

想做超過 50 張卡片時，打開 匯入 Anki 檔案 → 請 AI 製作 .apkg，輸入主題和卡片數量，PASS LOOP 會複製一段給能執行程式碼的 AI App 使用的請求。也可以附上你自己的照片、PDF、音訊或影片。打開 AI 給你的 .apkg 檔，選擇 分享 → PASS LOOP 即可。做出來的是正反面卡片。

匯出、備份、換新 iPhone

  • 匯出牌組：在牌組上選擇 匯出，要在 Anki 中開啟就選 Anki 牌組（.apkg） 並開啟 包含學習進度，或選擇 CSV（試算表）。
  • 備份：設定 → 學習資料 → 備份與還原 → 建立備份檔案。檔案包含你的卡片進度、牌組、牌組選項、筆記和圈圈小屋。
  • 自動備份：每天一次把學習資料存在 iPhone 上，並保留最新 7 份。其中不含圖片和音訊，若要完整備份，請建立備份檔案。

換新 iPhone

  1. 在舊 iPhone 上建立備份檔案，並包含圖片和音訊。
  2. 存到「檔案」App 或 iCloud 雲碟，或用 AirDrop 傳到新 iPhone。
  3. 在新 iPhone 上打開 PASS LOOP → 設定 → 學習資料 → 備份與還原 → 從備份檔案還原。下次打開 App 時就會完成還原。

PASS LOOP Ultra

  • Ultra 是一次性購買，包含 Listen 模式、圈圈小屋的 Ultra 收藏和9 種 App 圖示顏色。所有免費的功能都會一直免費。
  • 7 天免費試用：不會自動扣款。試用結束後只會鎖住 Ultra 功能，你的牌組、學習紀錄和金幣都會保留。
  • 支援家人共享，你的家庭群組也能使用 Ultra。
  • 回復購買：設定 → 支持 PASS LOOP → 回復購買項目。
  • 退款請透過 Apple 的 reportaproblem.apple.com 申請。退款後 Ultra 功能會關閉，但絕不會刪除你的牌組、紀錄或金幣。
  • 支持 PASS LOOP 裡的小費是自由的心意，不會解鎖任何功能。

Listen 模式

從學習畫面的耳機按鈕開始。使用耳機時：按一下暫停，按兩下為「普通」，按三下為「重來」。「困難」和「簡單」、「再聽一次」與「復原」都在 Listen 畫面上。卡片會用 iPhone 本身的語音朗讀，或使用在 iPhone 上執行的選用自然 AI 語音（需下載一次，約 400 MB；不會傳送任何資料到伺服器）。AI 語音需要記憶體 4 GB 以上的 iPhone，而且不朗讀中文：其他 iPhone 和中文卡片由 iOS 內建語音朗讀。更自然的 iPhone 語音可在 iOS 的 設定 → 輔助使用 → 語音內容 → 聲音 中免費下載。

小提醒

  • 只支援 iPhone，需 iOS 17 以上；沒有 iPad、Android 或網頁版。
  • App 支援英文、韓文、日文和繁體中文，會跟隨 iPhone 的語言設定。
  • 主畫面與鎖定畫面的小工具會顯示今天的卡片、連續學習和圈圈的天氣。長按主畫面即可加入 PASS LOOP。
  • 沒有同步，也沒有帳號。牌組用 .apkg 檔搬移，學習進度和圈圈小屋用備份檔案搬移。
  • Anki 的附加元件無法在 PASS LOOP 中執行。
  • 所有資料都存在你的 iPhone 上。請參閱隱私權政策。
